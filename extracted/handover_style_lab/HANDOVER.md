## 3. 核心决策（为什么是这七张、为什么这样动）

### 3.1 为什么选这六条风格线

不是"六个好看的画风"，而是按**观澜实际要用的场景**选的：

| 风格 | 承担的功能 | 结论 |
|---|---|---|
| ① 吉卜力水彩 | 环境/背景层 | **主风格之一**：负责"想待着" |
| ⑤ Q 版萌系 | 角色/互动层 | **主风格之一**：负责"想戳一下" |
| ② 新海诚光影 | 对外物料 | 门面，不做常驻（久了疲劳） |
| ③ 京都柔光 | 图鉴/教学 | 说明书气质，信息密度低 |
| ④ 90s 赛璐璐 | 彩蛋/回忆 | 低频高感知 |
| ⑥ 温柔奇幻 | 夜间/传说鱼 | 稀缺资源，一次只给一个场景 |
| ⑦ 经典赛璐璐 | ④ 的对照样本 | 说明"赛璐璐本体"和"复古滤镜"的区别 |

**推荐组合：① 环境 + ⑤ 角色**（卡通版主风格）；② 只做宣传；③ 做图鉴；④⑥ 做彩蛋。

### 3.2 为什么动图要分 3D / 2D

- **3D 纵深派（①②③⑤⑥）**：水是有厚度的介质。用慢推镜头 + 前后景差速位移 + 鱼穿层，才能让"缸"不变成"壁纸"。
- **2D 平面派（④⑦）**：赛璐璐的清晰感来自"色块边界是刀切的"。一旦加景深模糊/体积光/镜头视差，边界被软化，就变成"伪 3D 渲染"，两头不靠。

👉 **这是一个可复用的判断规则：风格本身对"空间"的态度，决定动效能不能加 3D。** 厚涂/水彩/光影系可以加；赛璐璐/版画/像素系不能加。

### 3.3 关键取舍（已发生，接手者不要再纠结）

1. **Q 版鱼的配色偏粉**，不是严格的宝莲灯银蓝红。这是为了 Q 版"马卡龙色"统一性做的取舍；如果要求物种准确，需重生成并接受可爱度下降。
2. **③ 京都柔光**实际更接近"柔光动画背景"而非典型 KyoAni 细线．若要当正式风格，需把"细线 + 两色阶"写进规范再重绘。
3. **④ 是复古变体**（加了褪色/颗粒/扫描线），**⑦ 才是赛璐璐本体**。两者不要混用。

## 7. 已知限制（如实交接）

1. **5 秒循环首尾不完全无缝**。做长片/宣传片需要交叉淡化或重剪，不能直接首尾相接。
2. **图片右下角有平台水印**（"AI生成"）。正式使用需裁切或按方向重绘。
3. **AI 生成的细节会漂**：同一提示词多次生成，水草种类/鱼的分布会变。本包固定了 7 张成品，重生成不保证一致。
4. **无音轨**。动图展厅是纯视觉；若要加环境音/水声，需另配。
5. **动图分辨率 1176×784**，不是 4K。适合网页/社媒，不适合大屏投放。
6. **这些图不能直接进 Three.js**。它们是 2D 参考，游戏内需要的是材质/描边/色阶参数（见下一节 A）。

## 8. 建议的下一步（按优先级）

### A. 把 ①+⑤ 落成卡通版实时参数（推荐先做）

目标：让卡通版不是"贴一张水彩图"，而是**实时渲染出这套语言**。

可落地的三组参数：

| 参数 | 吉卜力水彩（环境） | Q 版（角色） |
|---|---|---|
| 描边 | 无硬描边，用深度/法线做柔边 | 等宽深棕描边（屏幕空间 Sobel，宽度 1.5–2px） |
| 色阶 | 连续渐变 + 纸纹噪声 | 2–3 级 posterize，边界硬 |
| 高光 | 大面积柔光 | 单块硬高光 |
| 后期 | 水彩纸纹 + 轻微色散 | 无后期，保持干净 |

技术路径：Three.js `ShaderMaterial` 做 posterize + Fresnel 描边；或 `EffectComposer` 加一层 Sobel 边缘检测 + 纸纹叠加。**先做开关，不要替换现有渲染**，用 A/B 对比验证。

### B. 用七条素材剪一支 30 秒风格混剪

- 结构建议：3D 派快切（①②⑤）→ 2D 派骤停（④⑦）→ 回到 ① 收尾
- 卖点是"同一口缸的七种看法"，适合发小红书/B 站做冷启动
- 需要补：转场（交叉淡化/硬切）、字幕（风格名）、结尾落版

### C. 回到主线 R13（阶段一闭环）

名片卡 1080×1440 + 场景码 + 论坛报告，把"造→拍→发→开"收口。风格探索是支线，不阻塞主线。

## 9. 红线与注意事项（务必遵守）

1. **不要重命名包内文件**。两个 HTML 用相对路径引用 `style-lab/...`，改名即断图/断视频。
2. **改 HTML 前先重新读文件**。本项目历史上出现过外部编辑器注入 `data-page-node-id` 并回写覆盖的情况；批量改动一律"读最新 → 整文件重写 → 校验"。
3. **不要用截图目检代替数据断言**。至少检查：图片 `naturalWidth`、视频 `videoWidth/duration`、关键 DOM 存在、console error 为 0。
4. **不要把 AI 图当最终资产**，也不要把"风格样片"写进需求文档当作已实装。
5. **不要为了"更炫"给赛璐璐加 3D**。这会毁掉这套语言的核心特征。
6. 商用/公开发布前确认图像生成平台的授权条款；本包内素材仅作内部方向讨论。
